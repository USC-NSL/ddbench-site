Collect
We collect 60 historical bugs, confirmed and fixed upstream, from 13 open-source distributed systems.
Build
Each case pins the buggy commit in Docker, with a symptom report, debug context, and a hidden oracle that fails before the fix and passes after.
Evaluate
An agent gets the symptom and code, with or without the debug context, and passes if the oracle reports PASS on its patch.

Quick start 
git clone https://github.com/USC-NSL/DDBench && cd DDBench

# Build a case and confirm the bug
./bench.sh setup raft-358-negative-log-range
./bench.sh reproduce raft-358-negative-log-range

# Run the agent (add --context for debug context)
./bench.sh agent raft-358-negative-log-range --addon mini-swe-agent \
    --prompt "Fix the bug in SYMPTOM.md" \
    --config harness/configs/ddbench_prompt.yaml --output-dir out/

# Score a patch
./bench.sh eval raft-358-negative-log-range --patch my-fix.diff --json result.json
